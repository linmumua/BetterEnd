# BetterEnd 占用的原版方块状态

BetterEnd 的自定义方块通过 CraftEngine 借用原版方块状态做外观载体。其他插件（CE 资源包）不要再使用下面这些状态，否则两边方块会显示成同一个模型。

数据来源：

- 固定状态：`plugin/src/main/resources/craftengine/betterend/configuration/blocks/*.yml` 里写死的 `state:`（含模板参数展开），共 139 个。与服务器无关，任何服都一样。
- 自动分配状态：Folia 测试端 `plugins/CraftEngine/cache/visual_block_states.json` 中 `betterend:` 开头的条目，共 626 个。这是 `auto_state` 的实际分配结果，换服务器或调整资源包后可能变化，以目标服务器的 cache 为准。

## 给另一个插件的建议

- 优先用 `auto_state`，CE 会自动避开已分配的状态，不需要手动对照本表。
- 只有写死 `state:` 时才需要对照本表，下面列出的状态一个都不要用。
- 下表的家族已经被大量占用，新插件写死状态时尽量换别的家族：
  - `minecraft:note_block`：BetterEnd 自动分配 310 个
  - `minecraft:tripwire`：BetterEnd 自动分配 87 个
  - `minecraft:red_mushroom_block`：BetterEnd 自动分配 63 个
  - `minecraft:cave_vines`：BetterEnd 自动分配 48 个
  - `minecraft:brown_mushroom_block`：BetterEnd 自动分配 43 个
  - `minecraft:kelp`：BetterEnd 自动分配 18 个
  - `minecraft:mushroom_stem`：BetterEnd 自动分配 17 个
  - `minecraft:weeping_vines`：BetterEnd 自动分配 10 个
  - `minecraft:azalea_leaves`：BetterEnd 自动分配 8 个
  - `minecraft:sugar_cane`：BetterEnd 自动分配 7 个
  - `minecraft:flowering_azalea_leaves`：BetterEnd 自动分配 4 个
  - `minecraft:twisting_vines`：BetterEnd 自动分配 4 个
  - `minecraft:oak_sapling`：BetterEnd 自动分配 1 个
  - `minecraft:spruce_sapling`：BetterEnd 自动分配 1 个
  - `minecraft:birch_sapling`：BetterEnd 自动分配 1 个
  - `minecraft:jungle_sapling`：BetterEnd 自动分配 1 个
  - `minecraft:acacia_sapling`：BetterEnd 自动分配 1 个
  - `minecraft:cherry_sapling`：BetterEnd 自动分配 1 个
  - `minecraft:dark_oak_sapling`：BetterEnd 自动分配 1 个
- 同一个 cache 里其他包的占用（同样不可再用）：`minecraft:note_block` 579，`minecraft:mushroom_stem` 46，`minecraft:tripwire` 39，`minecraft:twisting_vines` 21，`minecraft:brown_mushroom_block` 20，`minecraft:cherry_leaves` 13，`minecraft:pale_oak_leaves` 13，`minecraft:azalea_leaves` 11，`minecraft:flowering_azalea_leaves` 9，`minecraft:sugar_cane` 8，`minecraft:kelp` 7，`minecraft:cactus` 6，`minecraft:heavy_weighted_pressure_plate` 4，`minecraft:weeping_vines` 3，`minecraft:pale_oak_sapling` 1。
